# CommonBackend

This backend foundation provides a production-ready Express shell for Krishna Footwear.

## Included
- Express application bootstrap
- Versioned API routing under `/api/v1`
- Health check endpoint
- CORS, Helmet, Morgan, Compression, Cookie Parser
- Rate limiting middleware
- Global response helpers
- Global error handling
- Deferred PostgreSQL and Redis configuration

## Pending implementation
- Authentication and authorization
- Product and category modules
- Cart, orders, and users modules
